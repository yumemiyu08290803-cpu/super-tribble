# 台本担当

## 長尺

- 本文は5000文字以上にする。
- 冒頭30秒で、検証する問い、最も強い公開事実、その事実が説明できない理由を出す。
- 公開事実、違和感、複数仮説、仮説の弱点、最後の具体的な問いを入れる。
- 公開事実とフィクション仮説を明確に分け、実在の人物・犯人・真相を断定しない。
- チャンネル登録への誘導を自然に入れる。

## Shorts

- 3本作る。1本目は核心、2本目は時系列の違和感、3本目は長尺へ行く理由にする。
- 本文は各400文字以上、`①`形式にする。
- 各ブロックは句点2つ。句点`。`と読点`、`の直後で必ず改行する。
- 「関連動画から」とチャンネル登録への誘導を自然に入れる。
- 画像指示は台本に書かない。

## 不合格

- 文字数未達、公開事実と推測の混同、導入の弱さ、具体的な問いの欠如。
